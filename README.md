# Pinku Clinic · ระบบจองคิวคลินิก (CPE361)

โปรแกรมสำหรับเจ้าหน้าที่คลินิก ใช้ลงทะเบียนผู้ป่วย จองคิวพบแพทย์ ค้นหาคิว ยกเลิกคิว และบันทึกว่าตรวจแล้ว
เขียนด้วย Python 3 + sqlite3 + Tkinter ซึ่งมากับ Python อยู่แล้ว ใช้ **tkcalendar** ทำปฏิทินเลือกวันเกิด
และมีหน้าเว็บดูตารางคิวแบบอ่านอย่างเดียว (`app.py`) เขียนด้วย **Flask** ให้คนที่ต่อ Wi-Fi เดียวกันเปิดดูได้
tkcalendar กับ Flask ต้องติดตั้งเพิ่ม 1 ครั้ง (ดูขั้นที่ 5)

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `clinic_db.sql` | คำสั่งสร้าง 6 ตาราง (รวมตารางผลการรักษา `treatments`) และข้อมูลตัวอย่าง (วันที่คิดจากวันที่รัน) |
| `create_db.py` | ลบ `clinic.db` เดิม สร้างใหม่จาก `clinic_db.sql` แล้วเติมช่องเวลาออกตรวจล่วงหน้า 30 วัน ใช้รีเซ็ตข้อมูลก่อน Demo |
| `sql_examples.py` | ตัวอย่าง SQL 10 ข้อ (SELECT JOIN, UPDATE, DELETE) พร้อมผลก่อนและหลัง |
| `main.py` | หน้าต่างหลัก แถบหัวโปรแกรม และ 3 แท็บ **ไฟล์ที่ใช้เปิดโปรแกรม** |
| `database.py` | เชื่อมต่อ `clinic.db` เปิด foreign key รัน SQL ด้วย `?` สรุปคิววันนี้ และแปลง error เป็นภาษาไทย |
| `header_bar.py` | แถบหัวโปรแกรม ชื่อ Pinku Clinic และตัวเลขสรุปคิววันนี้ (ทั้งหมด / ตรวจแล้ว / รอตรวจ / ยกเลิก) |
| `theme.py` | ชื่อโปรแกรม สี และฟอนต์ของทั้งโปรแกรม (ttk theme "clam") รวมสีแถวตามสถานะคิวที่หน้าเว็บใช้ด้วย |
| `dialogs.py` | หน้าต่างแจ้งเตือน 4 แบบ (ข้อมูล / เตือน / ผิดพลาด / ถามยืนยัน) ที่เข้ากับธีม ใช้แทน messagebox |
| `patient_tab.py` | แท็บ "ผู้ป่วย" ลงทะเบียนและแก้ไขข้อมูลผู้ป่วย (เลือกวันเกิดจากปฏิทิน) และดูประวัติการรักษา |
| `booking_tab.py` | แท็บ "จองคิว" ค้นผู้ป่วยด้วยเบอร์โทร แล้วเลือกแผนก แพทย์ วันที่ ช่องเวลาที่ว่าง |
| `search_tab.py` | แท็บ "ค้นหาและจัดการคิว" ค้นด้วยชื่อ เบอร์โทร หรือวันที่ แล้วยกเลิก หรือบันทึกว่าตรวจแล้วพร้อมผลวินิจฉัย (แถวมีสีตามสถานะ) |
| `app.py` | หน้าเว็บดูตารางคิวรายวัน (Flask) อ่านจาก `clinic.db` ชุดเดียวกับโปรแกรม ดูหัวข้อ "หน้าเว็บดูตารางคิว (app.py)" |
| `templates/` | `index.html` หน้าตาของหน้าเว็บ (ตารางวันละ 1 ตาราง กล่องสรุป 4 กล่อง สีแถว) ที่ `app.py` เติมข้อมูลลงไป |
| `requirements.txt` | รายชื่อไลบรารีที่ต้องติดตั้งเพิ่ม (`tkcalendar` และ `flask`) |
| `with_comments/` | โค้ดชุดเดียวกันที่มีคอมเมนต์ภาษาไทย: ไฟล์ `.py` 9 ไฟล์ (คอมเมนต์ท้ายทุกบรรทัด) และ `templates/index.html` (คอมเมนต์ HTML อธิบายแต่ละส่วน) ไว้อ่านและเตรียมตอบคำถาม |
| `docs/` | เอกสารประกอบ (ดูหัวข้อ "เอกสาร" ท้ายไฟล์นี้) |

โค้ดในโฟลเดอร์ `with_comments/` ทำงานเหมือนไฟล์ข้างนอกทุกบรรทัด ต่างกันแค่คอมเมนต์
ตอนรันจริงให้ใช้ไฟล์ข้างนอกทั้ง `main.py` และ `app.py` (`clinic.db` จะถูกสร้างไว้ข้างนอก ไม่ใช่ในโฟลเดอร์นี้)

## สิ่งที่ต้องมีในเครื่อง

- **Python 3.8 ขึ้นไป** จาก python.org ตอนติดตั้งให้ติ๊ก "Add python.exe to PATH" ส่วน "tcl/tk and IDLE" ติ๊กไว้ให้แล้วเป็นค่าเริ่มต้น (ต้องมี เพราะคือ Tkinter)
- **tkcalendar** ไลบรารีปฏิทิน และ **Flask** ไลบรารีทำหน้าเว็บของ `app.py` ติดตั้งพร้อมกันจาก `requirements.txt` ในขั้นที่ 5 (ติดตั้งครั้งเดียวต่อเครื่อง)
- **VS Code** และ Python extension ของ Microsoft
- **DB Browser for SQLite** (ฟรี) ไว้เปิดดูตารางใน `clinic.db`
- (ไม่บังคับ) **Microsoft Access** ถ้าจะเปิดไฟล์ `docs/clinic_access.accdb`

## วิธีรันใน VS Code ทีละขั้น

1. เอาโฟลเดอร์โปรเจกต์มาไว้ในเครื่อง เลือกได้ 2 แบบ ได้ไฟล์ชุดเดียวกัน ต่างกันแค่ชื่อโฟลเดอร์
   - **git clone** (ต้องมี Git ในเครื่อง) จะได้โฟลเดอร์ `pinku-hospital-queue` และดึงของใหม่ทีหลังได้ด้วย `git pull`
     ```
     git clone https://github.com/P1nkcha/pinku-hospital-queue.git
     ```
   - **Download ZIP** ในหน้า GitHub ของโปรเจกต์ กดปุ่ม **Code → Download ZIP** แล้วแตกไฟล์ จะได้โฟลเดอร์ `pinku-hospital-queue-main` (มี `-main` ต่อท้ายตามชื่อ branch) แบบนี้ไม่มีประวัติ git ถ้ามีของใหม่ต้องโหลด ZIP ใหม่

   ขั้นต่อไปเรียกโฟลเดอร์นี้ว่า "โฟลเดอร์โปรเจกต์"
2. เปิด VS Code → เมนู **File → Open Folder...** → เลือกโฟลเดอร์โปรเจกต์ (เปิดทั้งโฟลเดอร์ ไม่ใช่เปิดไฟล์เดียว)
3. เลือก Python interpreter: กด `Ctrl+Shift+P` → พิมพ์ **Python: Select Interpreter** → เลือก Python 3 ที่ติดตั้งไว้
4. เปิด Terminal: เมนู **Terminal → New Terminal** (หรือกด ``Ctrl+` ``)
5. ติดตั้ง tkcalendar และ Flask (ทำครั้งเดียวต่อเครื่อง ต้องต่ออินเทอร์เน็ต)
   ```
   python -m pip install -r requirements.txt
   ```
   `requirements.txt` ระบุ `tkcalendar==1.6.1` และ `flask==3.1.3` ไลบรารีที่ทั้งสองตัวต้องใช้ (เช่น babel ของ tkcalendar) จะถูกติดตั้งมาด้วยอัตโนมัติ
   ควรเห็น "Successfully installed ..." หรือ "Requirement already satisfied" ถ้าเคยติดตั้งแล้ว
   จะติดตั้งทีละตัวก็ได้
   ```
   python -m pip install tkcalendar
   python -m pip install flask
   ```
6. สร้างฐานข้อมูล
   ```
   python create_db.py
   ```
   ควรเห็นข้อความแบบนี้ (ตัวอย่างจากการรันวันที่ 31 ต.ค. 2026 วันที่จะเปลี่ยนตามวันที่รัน แต่จำนวนแถวเท่าเดิมทุกครั้ง)
   ```
   ลบ clinic.db เดิมแล้ว
   สร้าง clinic.db ใหม่เรียบร้อย
   เติมช่องเวลาล่วงหน้า 30 วัน: เตรียม 3720 ช่อง เพิ่มใหม่ 3689 ช่อง (มีอยู่แล้วในข้อมูลตัวอย่าง 31 ช่อง)

   จำนวนแถวในแต่ละตาราง
     departments: 5
     doctors: 10
     patients: 15
     schedules: 3739
     appointments: 30
     treatments: 15
   ช่วงวันที่ของช่องเวลาทั้งหมด: 2026-04-14 ถึง 2026-11-30
   ช่องเวลาตั้งแต่วันนี้: 2026-10-31 ถึง 2026-11-30 (3720 ช่อง)
   จำนวนคิวแยกตามสถานะ
     ตรวจแล้ว: 15
     จองแล้ว: 12
     ยกเลิก: 3
   คิวของวันนี้ (2026-10-31): 7 คิว
   คิวที่ตรวจแล้วแต่ยังไม่มีผลการรักษา: 0 คิว
   ```
   ครั้งแรกที่รันยังไม่มี `clinic.db` จึงไม่มีบรรทัด "ลบ clinic.db เดิมแล้ว"
7. เปิดโปรแกรม
   ```
   python main.py
   ```
8. (ถ้าต้องการ) ดูตัวอย่าง SQL
   ```
   python sql_examples.py
   ```
   กด Enter เพื่อไปทีละตัวอย่าง ไฟล์นี้แก้ข้อมูลจริง จึงต้องรัน `python create_db.py` อีกครั้งก่อน Demo
9. (ถ้าต้องการ) เปิดหน้าเว็บดูตารางคิว ให้คนที่อยู่ในวง LAN หรือ Wi-Fi เดียวกันดูรายการคิวได้
   ```
   python app.py
   ```
   แล้วเปิด http://127.0.0.1:5000 ในเบราว์เซอร์ วิธีเปิดจากมือถือและรายละเอียดอื่นดูหัวข้อ "หน้าเว็บดูตารางคิว (app.py)"

ถ้าพิมพ์ `python` แล้วขึ้นว่าไม่รู้จักคำสั่ง หรือเด้งไป Microsoft Store ให้ใช้ `py` แทน เช่น `py create_db.py` และ `py -m pip install -r requirements.txt`
ตรวจว่ามี Tkinter หรือไม่: `python -m tkinter` ต้องมีหน้าต่างเล็กๆ เด้งขึ้นมา

## หน้าเว็บดูตารางคิว (app.py)

หน้าเว็บนี้ใช้ดูคิวอย่างเดียว เปิดได้ทั้งจากเครื่องที่รันโปรแกรมและจากมือถือที่ต่อ Wi-Fi เดียวกัน
ข้อมูลมาจาก `clinic.db` ไฟล์เดียวกับโปรแกรม จองหรือยกเลิกคิวในโปรแกรมแล้วหน้าเว็บจะเปลี่ยนตาม

### แสดงอะไรบ้าง

- **ตารางวันละ 1 ตาราง** หัวตารางบอกวันที่และชื่อวัน เช่น `2026-10-31 วันเสาร์` ตารางของวันนี้มีป้าย **วันนี้** และกรอบหนากว่าวันอื่น
- **ลำดับวัน** วันนี้อยู่บนสุด ต่อด้วยวันข้างหน้าจากใกล้ไปไกล แล้ววันที่ผ่านมาแล้วจากใหม่ไปเก่า แสดงเฉพาะวันที่มีคิว ในแต่ละวันเรียงตามเวลา
- **กล่องสรุป 4 กล่อง** ใต้หัวของแต่ละวัน: คิวทั้งหมด / ตรวจแล้ว / รอตรวจ / ยกเลิก (คิวทั้งหมด = ผลรวมของอีก 3 กล่อง เหมือนแถบหัวในโปรแกรม) ตัวเลขนับด้วย SQL `GROUP BY work_date, status` ไม่ได้นับใน Python
- **คอลัมน์** เลขคิว เวลา ผู้ป่วย แพทย์ แผนก สถานะ
- **สีแถว** ใช้ค่าสีจาก `theme.py` ชุดเดียวกับแท็บค้นหาและจัดการคิวในโปรแกรม: พื้นส้มอ่อน = จองแล้ว · พื้นเขียวอ่อน = ตรวจแล้ว · พื้นเทาอ่อน = ยกเลิก ตัวหนังสือเป็นสีเข้มทุกแถว อ่านบนโปรเจกเตอร์ได้ชัด
- **รีเฟรชเอง** ทุก 10 วินาที หรือกด F5 เพื่อดูข้อมูลล่าสุดทันที

### วิธีรัน

1. ต้องมี `clinic.db` ก่อน (รัน `python create_db.py`)
2. เปิด Terminal อีกอันใน VS Code (กดปุ่ม **+** ที่แถบ Terminal) เพราะ Terminal เดิมอาจรัน `main.py` อยู่ โปรแกรมกับหน้าเว็บเปิดพร้อมกันได้
3. รัน
   ```
   python app.py
   ```
   Terminal จะขึ้นแบบนี้
   ```
    * Serving Flask app 'app'
    * Debug mode: off
   WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
    * Running on all addresses (0.0.0.0)
    * Running on http://127.0.0.1:5000
    * Running on http://<เลข IP ของเครื่อง>:5000
   Press CTRL+C to quit
   ```
   บรรทัด WARNING เป็นคำเตือนปกติของ Flask ว่าเป็นเซิร์ฟเวอร์สำหรับพัฒนาโปรแกรม ใช้ในงานนี้ได้ ไม่ต้องแก้
4. เปิดเบราว์เซอร์ในเครื่องเดียวกันไปที่ http://127.0.0.1:5000
5. ใช้เสร็จแล้วหยุดเซิร์ฟเวอร์: คลิกใน Terminal ที่รัน `app.py` แล้วกด `Ctrl+C`

### เปิดจากมือถือที่ต่อ Wi-Fi เดียวกัน

1. ให้คอมกับมือถือต่อ Wi-Fi เดียวกัน (หรือให้คอมต่อ Hotspot ของมือถือเครื่องนั้น)
2. ดูบรรทัด `Running on http://<เลข IP ของเครื่อง>:5000` บรรทัดที่**ไม่ใช่** 127.0.0.1 แล้วพิมพ์ที่อยู่นั้นในเบราว์เซอร์ของมือถือ ต้องขึ้นต้นด้วย `http://` และมี `:5000` ต่อท้าย (127.0.0.1 ใช้ได้เฉพาะในเครื่องตัวเอง)
3. ครั้งแรกที่รัน Windows อาจเด้งหน้าต่าง **Windows Security Alert** ของ Windows Defender Firewall ถามว่าจะให้ Python ใช้เครือข่ายแบบไหน ให้ติ๊กเฉพาะ **Private networks** ไม่ติ๊ก **Public networks** แล้วกด **Allow access**
   เพราะ Public networks หมายถึง Wi-Fi สาธารณะ เช่น ร้านกาแฟหรือสนามบิน ถ้าเปิดไว้ คนแปลกหน้าในวงนั้นจะเข้าหน้าเว็บในเครื่องเราได้

### ทำไมหน้าเว็บอ่านอย่างเดียว และตั้ง debug=False

- ใครก็ตามที่อยู่ใน Wi-Fi เดียวกันเปิดหน้านี้ได้โดยไม่ต้องล็อกอิน หน้าเว็บจึงทำได้แค่ดึงข้อมูลด้วย SELECT มาแสดง ไม่มีปุ่มจอง ยกเลิก หรือแก้ข้อมูล การเปลี่ยนข้อมูลทำได้เฉพาะในโปรแกรม (`main.py`) ที่เจ้าหน้าที่ใช้ และค่าที่ใส่ในคำสั่ง SQL ส่งผ่าน `?` ไม่ได้ต่อเป็นข้อความ
- `app.py` รันด้วย `app.run(debug=False, host="0.0.0.0", port=5000)` ถ้าเปิด `debug=True` เวลาเกิด error Flask จะแสดงหน้าดีบักที่เห็นโค้ดและรายละเอียดภายใน และมีช่องให้พิมพ์คำสั่ง Python รันบนเครื่องเราได้ (มีรหัส PIN กันไว้ แต่ไม่ควรเสี่ยง) เมื่อหน้าเว็บเปิดให้คนอื่นในวงเดียวกันเข้าถึง จึงต้องปิด debug ไว้
- `host="0.0.0.0"` ทำให้เครื่องอื่นในวง Wi-Fi เดียวกันเข้าได้ และ `port=5000` คือเลขพอร์ตที่ต่อท้ายที่อยู่เว็บ

## ก่อนขึ้นนำเสนอทุกครั้ง

1. ปิด DB Browser for SQLite
2. รัน `python create_db.py` (ข้อมูลตัวอย่างคิดวันที่จากวันที่รัน จึงมีคิวของ "วันนี้" ให้ Demo เสมอ และช่องเวลาจองได้ถึงอีก 30 วันนับจากวันที่รัน)
3. รัน `python main.py`
4. ถ้าจะโชว์หน้าเว็บ เปิด Terminal อีกอันแล้วรัน `python app.py`

## เปิด clinic.db ด้วย DB Browser for SQLite

1. ดาวน์โหลดจาก https://sqlitebrowser.org/dl/ เลือกตัวติดตั้งสำหรับ Windows
2. เปิดโปรแกรม → **Open Database** (`Ctrl+O`) → เลือก `clinic.db` ในโฟลเดอร์โปรเจกต์
   ตอนนำเสนอแนะนำให้กดลูกศรข้างปุ่ม Open Database แล้วเลือก **Open Database Read Only** กันเผลอแก้ข้อมูลและกันไฟล์ถูกล็อก
3. แท็บ **Database Structure** ดูตาราง คอลัมน์ ข้อบังคับ และ index `one_active_appt_per_slot`
4. แท็บ **Browse Data** เลือกตารางจากช่อง Table เพื่อดูข้อมูลทีละตาราง
   หลังทำรายการในโปรแกรม ให้กดปุ่ม Refresh ในแท็บนี้เพื่อดูข้อมูลล่าสุด
5. แท็บ **Execute SQL** พิมพ์คำสั่ง SELECT แล้วกด `Ctrl+Return` หรือ `F5` เพื่อรัน
6. ถ้าแก้ข้อมูลใน DB Browser ต้องกด **Write Changes** (`Ctrl+S`) ไม่งั้นไฟล์จะค้างล็อก และโปรแกรมของเราบันทึกไม่ได้

## ปัญหาที่อาจเจอ

| อาการ | วิธีแก้ |
| --- | --- |
| เปิดโปรแกรมแล้วขึ้น "ไม่พบฐานข้อมูล" | รัน `python create_db.py` ก่อน |

| รัน `python app.py` แล้วขึ้น `No module named 'flask'` | ยังไม่ได้ติดตั้ง Flask รัน `python -m pip install -r requirements.txt` ด้วย Python ตัวเดียวกับที่ใช้รัน |
| `create_db.py` บอกว่าลบ `clinic.db` ไม่ได้ | ปิด DB Browser แล้วรันใหม่ |
| โปรแกรมแจ้ง "ฐานข้อมูลกำลังถูกใช้งานโดยโปรแกรมอื่น" (รอประมาณ 5 วินาทีก่อนแจ้ง) | กด Write Changes ใน DB Browser หรือปิด DB Browser |
| ภาษาไทยในโค้ดเป็นตัวแปลกๆ | ดูมุมขวาล่างของ VS Code ต้องเป็น UTF-8 |
| Terminal มีบรรทัด `[ข้อมูลสำหรับผู้พัฒนา] SQLite error: ...` | เป็นข้อความสำหรับคนเขียนโปรแกรม ผู้ใช้จะเห็นเป็นข้อความภาษาไทยบนหน้าจอเท่านั้น |
| หน้าเว็บขึ้น "ยังไม่มีฐานข้อมูล clinic.db กรุณารัน python create_db.py ก่อน" | รัน `python create_db.py` แล้วกด F5 ที่หน้าเว็บ |
| รัน `python app.py` แล้วขึ้น `Port 5000 is in use by another program` (พอร์ต 5000 ถูกใช้อยู่) | ส่วนมากเป็น `app.py` ตัวเก่าที่ยังรันค้างใน Terminal อื่น ให้ไปที่ Terminal นั้นแล้วกด `Ctrl+C` หรือกดรูปถังขยะปิด Terminal นั้น แล้วรันใหม่ ถ้ายังไม่หาย รัน `netstat -ano \| findstr :5000` ดูตัวเลขท้ายบรรทัด (PID) แล้วปิดโปรแกรมที่มี PID นั้นใน Task Manager แท็บ Details |
| มือถือเปิดหน้าเว็บไม่ได้ | ตรวจทีละข้อ: (1) มือถือกับคอมต่อ Wi-Fi เดียวกัน (2) ใช้เลข IP จากบรรทัด `Running on` ที่ไม่ใช่ 127.0.0.1 ขึ้นต้นด้วย `http://` และมี `:5000` ต่อท้าย (3) `app.py` ยังรันอยู่ (4) Firewall อนุญาต Private networks แล้ว และ Wi-Fi ที่ต่อตั้งเป็น Private (Settings → Network & internet → Wi-Fi → ชื่อ Wi-Fi → Network profile type → Private network) ถ้าเผลอกด Cancel ตอน Firewall ถาม ไปที่ Windows Security → Firewall & network protection → Allow an app through firewall แล้วติ๊ก Private ให้ Python (5) Wi-Fi ของมหาวิทยาลัยหรือร้านกาแฟบางที่ไม่ให้เครื่องในวงเดียวกันเชื่อมกัน ให้ใช้ Hotspot จากมือถือแทน |

กดปุ่ม Run ▶ มุมขวาบนของ VS Code ก็เปิดโปรแกรมได้ เพราะโปรแกรมหา `clinic.db` จากโฟลเดอร์ของตัวเองเสมอ
